## What's new — 5 November 2026

### Try 3mpwrapp on the demo page

The [Try 3mpwrapp](/demo/) page now embeds the real web app at [app.3mpwrapp.ca](https://app.3mpwrapp.ca/) — not a preview host. On the same page you can try document stamps (date, case number, document type) on sample text in your browser. Nothing is uploaded.

### Web app: install, refresh, and deep links

The web app now includes an install manifest, a service worker, and a fallback so refreshing or opening a deep link stays in the app instead of a missing page.
