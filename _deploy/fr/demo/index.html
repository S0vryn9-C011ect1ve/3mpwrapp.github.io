Démonstration interactive de 3MPWRAPP

🎯 Démonstration interactive de 3MPWRAPP

Essayez l'application maintenant - Aucune installation requise

Explorez les fonctionnalités révolutionnaires construites PAR et POUR la communauté des personnes handicapées.

🚀 Essayez l’application Web bêta en direct

Prêt à explorer ? Notre version Web bêta est maintenant disponible directement dans votre navigateur.

🌐 Lancer l'application Web bêta → 📖 Voir toutes les fonctionnalités

🔒 Note de confidentialité

Votre vie privée est garantie : L'application Web bêta fonctionne entièrement dans votre navigateur. Toutes les données restent sur votre appareil - aucune information personnelle n'est envoyée à nos serveurs. Utilisez le mode invité pour essayer sans compte.

En savoir plus sur notre engagement en matière de confidentialité →

📱 Aperçu des fonctionnalités principales

1. 🗂️ Casier à preuves

Stockage sécurisé de documents avec chiffrement de niveau militaire

Ce que vous pouvez faire :

  • Téléchargez et organisez des documents importants
  • Créez des collections thématiques (médicales, juridiques, correspondance)
  • Chiffrez tout avec AES-256 avant le stockage
  • Accédez hors ligne - aucune connexion Internet requise
  • Sauvegardez sur VOTRE propre cloud (Google Drive, Dropbox)

Essayez-le :

  1. Ouvrez le Casier à preuves
  2. Créez une nouvelle collection
  3. Téléchargez un document de test
  4. Explorez les options de chiffrement et de sauvegarde

2. ✍️ Assistant de lettres

22 modèles professionnels pour appels et plaidoyer

Ce que vous pouvez faire :

  • Choisissez parmi 22 modèles prêts à l’emploi
  • Personnalisez avec vos informations
  • Guidance étape par étape pour chaque lettre
  • Exportez en format PDF ou Word
  • Aucun juridique requis !

Modèles disponibles :

  • Demandes d’appel
  • Plaintes de discrimination
  • Demandes d’accommodement
  • Demandes d’accès à l’information
  • Et 18 autres !

3. 💪 Centre de bien-être

Suivez l’humeur, les symptômes, l’énergie et les médicaments

Ce que vous pouvez faire :

  • Compteur de cuillères - Suivez l’énergie avec la théorie des cuillères
  • Journal de l’humeur - Suivi quotidien avec graphiques visuels
  • Suivi des symptômes - Patterns et déclencheurs au fil du temps
  • Rappels de médicaments - Ne manquez jamais une dose
  • Rapports d’export - Partagez avec les fournisseurs de soins de santé

Essayez-le :

  1. Ouvrez le Centre de bien-être
  2. Enregistrez votre niveau d’énergie actuel avec le compteur de cuillères
  3. Explorez le journal de l’humeur et les trackers de symptômes

4. 🏘️ Forums communautaires

Espaces sûrs spécifiques aux provinces pour se connecter

Ce que vous pouvez faire :

  • Rejoignez des forums spécifiques aux provinces/territoires
  • Connectez-vous avec d’autres personnes ayant des expériences similaires
  • Partagez des ressources et des conseils
  • Trouvez des mentors pairs
  • Participation 100% anonyme si souhaité

Forums disponibles :

  • Les 10 provinces
  • Les 3 territoires
  • Communautés autochtones
  • Forums linguistiques (6 langues autochtones)

5. 🔄 Automatisation du flux de travail juridique

Guidance étape par étape pour les appels

Ce que vous pouvez faire :

  • Suivez votre chronologie de cas avec des échéances
  • Obtenez des rappels automatiques pour les dates importantes
  • Téléchargez des modèles pour chaque étape
  • Suivez la progression à travers le processus d’appel
  • Aucun avocat requis pour commencer

6. 🗣️ Support de langues autochtones

6 langues avec protocoles culturels

Langues prises en charge :

  • Cri
  • Ojibwé
  • Inuktitut
  • Micmac
  • Mohawk
  • Déné

Protocoles culturels :

  • Traduction respectueuse de la culture
  • Garde du savoir traditionnel
  • Guidance des aînés intégrée
  • Options de partage communautaire

7. ♿ Barre d’outils d’accessibilité

Fonctionnalités révolutionnaires pour tous les handicaps

Fonctionnalités cognitives :

  • Compteur de cuillères (suivi de l’énergie)
  • Bouton de simplification d’urgence
  • 3 modes de complexité (Simple/Standard/Avancé)
  • Rappels de pause personnalisables

Support de la dyslexie :

  • Polices adaptées à la dyslexie (OpenDyslexic, Dyslexie)
  • Superposition visuelle pour réduire le contraste
  • Guide de ligne pour surligner le texte actuel
  • Espacement réglable des lettres

Support visuel :

  • Lecteurs d’écran (NVDA, JAWS, VoiceOver, TalkBack)
  • Ratios de contraste 7:1 (niveau AAA)
  • Mode contraste élevé
  • Mode sombre complet

Support moteur :

  • Navigation complète au clavier
  • Cibles tactiles 44x44px
  • Support de contrôle vocal
  • Aucune limite de temps sur les actions

🎯 Cas d’utilisation

Pour les travailleurs blessés :

  • Organisez tous les dossiers médicaux en un seul endroit sécurisé
  • Suivez les demandes et appels d'indemnisation
  • Générez des lettres professionnelles pour l'employeur/l'assureur
  • Connectez-vous avec d'autres personnes qui ont traversé des situations similaires
  • Suivez les impacts sur la santé mentale et le bien-être

Pour les personnes handicapées :

  • Accédez à des outils d'accessibilité révolutionnaires (compteur de cuillères, mode d'urgence)
  • Trouvez des ressources spécifiques aux handicaps pour votre province
  • Connectez-vous avec la communauté des personnes handicapées
  • Suivez les accommodations et les demandes
  • Utilisez des modèles pour des lettres de plaidoyer

Pour les défenseurs et supporters :

  • Organisez les preuves pour plusieurs personnes que vous aidez
  • Accédez à des modèles professionnels pour le plaidoyer
  • Suivez les dossiers et les échéances
  • Partagez des ressources avec la communauté
  • Connectez les gens avec des mentors pairs

❓ Questions fréquentes

Q : L’application Web bêta est-elle sûre ?
R : Oui ! Toutes les données restent sur votre appareil. Nous ne collectons aucune information personnelle. Le chiffrement de bout en bout est activé par défaut.

Q : Puis-je utiliser l’application Web sans créer de compte ?
R : Oui ! Le mode invité vous permet d’essayer toutes les fonctionnalités sans inscription.

Q : Mes données seront-elles synchronisées entre les appareils ?
R : Si vous créez un compte, oui. Sinon, les données restent locales sur votre appareil. Vous contrôlez toujours où vos données vont.

Q : L’application fonctionne-t-elle hors ligne ?
R : Oui ! La plupart des fonctionnalités fonctionnent entièrement hors ligne. Les données sont stockées localement et synchronisées lorsque vous êtes en ligne (si vous choisissez).

Q : Est-ce vraiment gratuit ?
R : Oui, 100% gratuit pour toujours. Pas d’abonnements, pas de niveaux payants, pas de coûts cachés.
